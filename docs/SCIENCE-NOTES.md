方案 §04 图形语言要求：**科研图形必须显示单位、变量或数据来源，不做无语义装饰。**

`src/js/science/` 下的地形与流场是**示意性解析模型**，用于建立界面的图形语言，

## 1. 海沟纵剖面 `science/bathymetry.js`

**断面**　横穿马里亚纳海沟（挑战者深渊附近）的东西向断面，长 240 km，
归一化横坐标 `x ∈ [0,1]`，`x=0` 为西端（太平洋侧），`x=0.5` 为海沟轴部。

**模型**　基线平原深度叠加四个解析项：

| 项 | 形式 | 参数 | 物理含义 |
|---|---|---|---|
| 基线 | 常数 | 5800 m | 西太平洋深海平原 |
| 外缘隆起 | 高斯（负） | −430 m @ x=0.24, σ=0.055 | 板块下弯前的上拱 |
| 海沟轴部 | `A·exp(−\|t\|^1.35)` | A=5120 m, 半宽 0.115（≈27.6 km） | V 形沟槽 |
| 弧前斜坡 | smoothstep（负） | −3700 m, x: 0.60→0.94 | 向岛弧爬升 |
| 弧前海山 | 高斯（负） | −950 m @ x=0.875, σ=0.042 | 海山 |
| 小尺度起伏 | 三个正弦叠加 | ±~180 m | 海底粗糙度 |

轴部附近用 `1 − gauss(x, 0.5, 0.12)` 窗口抑制起伏，保证轴深恰为标称值。

**验证基线**（`node` 直跑 `science/`，2026-08-19）

```
外缘隆起局部浅点  5,570 m @ x=0.237      （较平原浅 230 m，形态成立）
海沟轴深          10,913 m @ x=0.501     （标称 10,920 m）
x=0.385           7,729 m                （距轴 ~27 km）
x=0.875           1,591 m                （弧前海山峰）
```

## 2. 三层环流速度场 `science/flow-field.js`

**变量**　`u` 纬向流速（m s⁻¹，**东向为正**）；`w` 垂向速度（m s⁻¹，**向下为正**）。

**层结构**　三个高斯核叠加：

| 层 | 核心深度 | 特征半宽 σ | 核心流速 `uCore` | 方向 |
|---|---|---|---|---|
| 上层环流 | 350 m | 1150 m | +0.135 m s⁻¹ | 东向 |
| 中层环流 | 3400 m | 2000 m | −0.085 m s⁻¹ | 西向 |
| 深渊层环流 | 8600 m | 2100 m | +0.052 m s⁻¹ | 东向 |

**关键设计：权重不归一化。**
归一化会把"远离所有层核心"的深度强行抬到某层核心流速，而实测中该处应为弱流。
不归一化时权重自然衰减 —— 剖面在近表、近底、层间过渡处都趋弱，
且各层极值恰好落在核心深度上。这一点由数值校验确认（见下）。

**附加项**

- **底边界层**：海底以上 220 m 内流速线性衰减至 0（贴底摩擦）。
- **侧边界**：断面两端 6% 范围内 smoothstep 收敛到 0，防止粒子在边缘堆成直线。
- **地形跟随**：`w = u · (dz/dx) · exp(−h/900)`，h 为离底高度。
- **横向摆动**：`1 + 0.22·sin(14x + 1.9i + ωt)`，周期 18 天，表达流核摆动，非装饰噪声。

**验证基线**

```
零交叉（流向反转）    1,643 m / 6,275 m
上层    0 → 1,643 m      峰值  +0.146 m s⁻¹ @   275 m
中层    1,643 → 6,275 m  峰值  −0.094 m s⁻¹ @ 3,434 m
深渊层  6,275 → 10,920 m 峰值  +0.041 m s⁻¹ @ 8,585 m
表层  u = +0.136 m s⁻¹     近底(−30 m) u = +0.002 m s⁻¹   海底以下 u = 0
```

峰值深度 275 / 3434 / 8585 与设定核心 350 / 3400 / 8600 吻合 ✓

## 3. 内潮波束模态 `science/flow-field.js` (mode: `'tides'`)

**周期**　M2 分潮，12.4206 h。相位用真实角频率 `ω = 2π/T`，
场景把墙钟时间按 `TIME_SCALE` 放大后传入（见 §5）。

**几何**　两条特征线自海沟两侧斜坡的临界点向外上方传播：

```
(x=0.398, 7,300 m) → (x=0.116, 0 m)      向西上传
(x=0.602, 7,300 m) → (x=0.884, 0 m)      向东上传
```

特征线斜率 0.108（无量纲），波束半宽 900 m，沿程 e 折衰减尺度 Δx=0.34。
质点速度**平行于波束**（内波的运动学特征），振幅 0.062 m s⁻¹。

**验证基线**（x=0.30, z=4760 m，正落在西侧波束上）

```
纯环流             u = −0.0491 m s⁻¹
叠加内潮 · 相位 0    u = −0.0108 m s⁻¹
叠加内潮 · 半周期后  u = −0.0885 m s⁻¹
```

围绕背景流振荡 ±0.039 m s⁻¹，半周期反相 ✓

## 4. 垂向流速剖面 `science/profile.js`

采样 160 点，从表面到海底。除 `u(z)` 外给出：

- **离散度带** `σ(z) = 0.013 + 0.19·|u| + 0.02·exp(−(floor−z)/400)`
  —— 示意性观测标准差，随流速增大、近底样本变少而增大。图上必须标注"阴影为示意离散度"。
- **零交叉深度** —— 三层结构最硬的证据点，图上单独标注。
- **`readAt(profile, z)`** —— 线性插值读数，供悬停十字线。

## 5. 动画时间尺度（重要）

真实流速 0.135 m s⁻¹ 走完 240 km 断面需约 20 天。逐帧按真实时间平流，画面完全静止。

场景层（`scenes/trench-scene.js`）用 `TIME_SCALE` 把墙钟秒放大为海洋时间秒。
**这是渲染层的加速，不是物理量的改变** —— `science/` 收到的 `time` 始终是海洋时间秒，
M2 周期等物理常数保持真实。

页面上必须标注加速倍数，符合方案「不做无语义装饰」的要求。

## 6. 地图投影 `science/projection.js`

等距圆柱（Plate Carrée）+ 中央纬度余弦校正，范围 105–150°E / 2–28°N。
**岸线为粗略简化多边形，图面已明示"示意图 · 简化岸线，非制图产品"**（ADR-006）。
站位坐标为真实经纬度，投影后误差在本图尺度下不可见。
P3 阶段替换为 MapLibre + 真实底图时，只需改写 `figures/station-map.js`。

## 7. 回归方式

`science/` 是纯层，可脱离浏览器直接跑（ADR-002 的直接收益）：

```bash
node --input-type=module -e "
import { velocityProfile } from './src/js/science/profile.js';
const p = velocityProfile();
console.log(p.crossings, p.layers.map(l => [l.peakU, l.peakDepthM]));
"
```

改动 `bathymetry.js` / `flow-field.js` 后必须重跑，与本文件的**验证基线**逐项比对。
数值变化必须是有意为之，并在本文件更新基线。
