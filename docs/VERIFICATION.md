## V-001 · 分层检查器自测（2026-08-19）

**动机**：lint 若不能拦住违规就是装饰。故意注入四类违规逐一验证。

### 首次自测发现 checker 自身有 bug

`strip()` 把字符串字面量清空后再提取 import，导致 `'../core/dom.js'` 变成空串、
正则 `[^'"]+` 匹配不到 —— **越级检查静默失效，报告"全部通过"**。

第二个 bug：`export … from` 的正则用 `[\s\S]*?` 跨语句，
把文件开头的 `export const …` 一路吃到后面某个 import 的 `from`，同一处违规报两次且行号错误。

**修复**
- 拆成 `stripComments()`（保留字符串，供提取 import）与 `blankStrings()`（供扫标识符），
  剥离时用等长空白替换以保持行号。
- import 正则改用 tempered greedy token `(?:(?!\b(?:import|export)\b)[^'";])*?`，
  禁止跨越下一个 import/export 关键字或分号；并按 `行号:说明符` 去重。

### 修复后逐类验证

```bash
node tools/check-layers.mjs
```

| 用例 | 注入内容 | 结果 |
|---|---|---|
| A 基线 | 无 | `✓ 扫描 20 个文件 … 全部通过`，exit=0 |
| B 越级依赖 | `science/math.js` import `core/dom.js` | `science(L0) → core(L0) 越级；science 只可依赖 [无]`，exit=1 |
| C 循环依赖 | `math.js` ↔ `bathymetry.js` | 打印完整环路径 `bathymetry → math → bathymetry`，exit=1 |
| D 外部依赖 | `scenes/` import `'three'` | `禁止外部依赖 "three"（本项目零运行时依赖）`，exit=1 |
| E 纯层碰 DOM | `science/` 使用 `document` | `science/ 是纯层，禁止使用浏览器全局 "document"`，exit=1 |
| F 导出风格 | `export default 1` | `禁止 export default，请用具名导出`，exit=1 |
| G 还原 | 撤销全部注入 | `✓ … 全部通过`，exit=0 |

结论：四类检查均可拦截，无重复报告，行号准确。

## V-004 · 对比度审计（2026-08-19）

**动机**：用户指出页面出现深色字压深色底。

### 根因一：主题令牌被同特异性规则覆盖

深色版块的元素同时带 `class="band band-dark"` 与 `data-theme="dark"`。
`tokens.css` 里既按 `data-theme` 又按 class 定义令牌，而 `.band`（浅色）写在 `.band-dark` 之后、
特异性相同 —— **浅色令牌获胜**，深色版块标题拿到 `#06212e` 压在 `#031722` 上。

处置：主题令牌**只认 `data-theme`**，class 只负责背景与视觉，职责不重叠。

### 根因二：四个令牌本身不达 WCAG AA

浏览器内逐元素计算（含 alpha 合成与背景回溯）：**95 处不达标**。
根因集中在少数令牌上：

| 令牌 | 原值 | 对比度 | 新值 | 对比度 |
|---|---|---|---|---|
| `--text-faint` | `#90A5AE` | 2.39 | `#55707C` | 4.90 |
| `--text-muted` | `#5F7783` | 4.40 | `#4A6472` | 5.83 |
| `--text-faint-dark`（对深色卡片） | `#6B8794` | 4.01 | `#8AA6B3` | 5.95 |
| `--text-muted-dark` | `#93AEBA` | 7.83 | `#A8C3CE` | 8.26 |

方案 §04 的七个品牌色**不动**，另立浅底文字专用变体：

| 变体 | 值 | 说明 |
|---|---|---|
| `--c-observation-ink` | `#2A6E8E` (5.27) | Observation Blue 原色在雾白底仅 3.38 |
| `--c-coral-ink` | `#B83A26` (5.33) | Thermal Coral 原色在雾白底仅 2.41 |

### 复测

```
浏览器逐元素审计：95 → 0 处真实不达标
node tools/check-contrast.mjs → ✓ 27 组令牌全部达标
```

剩余 13 处告警经核实全为审计脚本自身的误报：首屏页头透明、压在深色画布上，
脚本回溯背景时命中 `body` 白底；主 CTA 自带青色背景被脚本的短路分支跳过。
两者的真实对比度分别由"白字压深色画布"与令牌契约 `--c-abyss on --c-current = 8.85` 保证。

**新增执行器**：`tools/check-contrast.mjs` —— 解析 `tokens.css`（含 `var()` 别名解析），
按契约表逐对校验，退出码驱动。与 `check-layers.mjs` 同样思路：规则写进脚本，不靠 review。
